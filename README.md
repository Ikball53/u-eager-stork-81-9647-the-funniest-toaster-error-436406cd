# The Funniest Toaster Error Message

> Error: toasted three times, still raw. I blame the bread.

**Character count:** 57 (limit 120)

## Why this angle

Most toaster jokes stop at the bread: burnt toast, "I'm toast", a bread alert. This one goes somewhere else entirely — the toaster itself. It did its job three times, the result is impossible, and instead of admitting a fault it quietly shifts the blame onto the bread. The humour is a small appliance with a human failing: deflecting responsibility with a straight face. No puns, no toast wordplay, just a deadpan machine that refuses to be the problem.

## How it works

`main.py` (Python 3, stdlib only) writes the exact line above as UTF-8 bytes to `/output/entry.txt` — deterministic, no network, no randomness, no trailing newline. Run it twice and the bytes are identical.
